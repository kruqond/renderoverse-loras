## Chichi — Dragon Ball Z

Created by [**NSFWstudio**](https://www.patreon.com/nsfwstudio). The [original Renderoverse release](https://renderoverse.com/model/chichi-dragon-ball-z) provides the source listing, examples and version information.

This mirror contains the unchanged **1.0.0** adapter. It is not a standalone checkpoint. Its embedded metadata identifies the base as **AnyIllustrious XL v0.1.1 / SDXL epsilon**.

### Download and use

Get `chichi-renderoverse.safetensors` from this repository's **Releases** section. In ComfyUI, place it in `ComfyUI/models/loras` and load it with a compatible SDXL checkpoint using a Load LoRA node. Adjust the strength for your checkpoint and prompt.

Original source instructions:

> Character trigger: chichi_renderoverse, outfit trigger: Chichioutfit
